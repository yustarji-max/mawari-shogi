遊び方

基本

4人で盤の外周を時計回りに進みます。遊ぶ人が少ない席はCPUが担当します。金4枚の合計点だけ進み、最初に王将へ出世した人が1位です。

金：表1点／裏0点／横立ち5点／縦立ち10点

出世

角にぴったり止まると1段階出世します。0で角に止まっている場合も出世します。

歩 → と → 香 → 成香 → 桂 → 成桂 → 銀 → 成銀 → 角 → 馬 → 飛 → 龍 → 王

戦争

盤の向かい側で駒同士が正面から向き合うと戦争です。おんぶ中でも全員が別々に金を振り、個人順位を決めます。戦争後はおんぶを解消します。

2人：出世(+1)／降格(-1)

3人：大出世(+2)／現状維持(0)／大降格(-2)

4人：大出世(+2)／出世(+1)／降格(-1)／大降格(-2)

勝負振り

戦争中だけ高速ゲージが表示されます。指を離した瞬間、金の印が中央線に近いほど5点・10点が出やすくなります。

おんぶ

同じマスへ追いつくと自動で上に乗ります。3段・4段も可能です。下の駒が進むと上の駒も一緒に進みます。

上の駒の番で1以上なら降りて移動します。0なら乗ったままで、次に下の駒が動くとまた一緒に進みます。角で出世してもおんぶは続きます。

おんぶ中に複数人が同時に王になった場合は同点1位です。
