まわり将棋 v1.0.49

回っている時間の単調さを減らす演出を追加。

1. 出世の予兆
・次の角まで3マス以内になると「出世まで 3 / 2 / 1」
・角上では「0で出世」
・新ルールは追加せず、既存ルールの期待値だけ見える化

2. 戦争の予兆
・6マス以内に対面戦争になる目があると「戦争 N」
・4マス以内では相手駒が控えめに脈動
・戦争確定前から相手を意識できるようにした

3. 移動の手触り
・出世ランクが上がるほど、同じ木駒の移動音を少し強く
・高ランクほど移動間隔もごくわずかに重く
・派手な追加演出ではなく、駒の格が感触に出る方向

4. 戦争ゲージ
・高目補正は人間プレイヤー専用
・CPUは戦争中も必ず通常確率
・performRoll側にも防御を入れ、CPUにtierが渡っても無効

5. 俸禄音
・一周＋50両：短いチャリン
・戦争で獲得：上向きの金属音
・戦争で取られる：低く短い金属音
・追加音声ファイル不要（Web Audio生成）

6. 出世表
・実際のHTML構造 #ladder / #rankRows に合わせて横型を修正
・左「歩」→右「王」の順に修正
・色丸は各ランク名の下に配置
・盤の見栄えを崩さず盤幅と揃える
